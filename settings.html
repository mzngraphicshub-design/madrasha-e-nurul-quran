Login & Access

কোন user type system-এ login করতে পারবে এবং default access control।

Admin Login

Administrator সম্পূর্ণ system পরিচালনা করতে পারবে।

Teacher Login

Teacher-কে প্রয়োজনীয় page অনুযায়ী access দেওয়া হবে।

Student Login

Student ID + Roll Number দিয়ে student portal access।

Teacher Access System: Teacher-এর permission আলাদাভাবে নির্ধারণ করা যাবে। Permission না থাকা page Dashboard menu-তে দেখানো হবে না। একই permission guard ব্যবহার করে direct URL access-ও বন্ধ করা হবে।

Password Change

বর্তমান Admin account-এর password পরিবর্তন করুন।

Strong Password Requirement কমপক্ষে 8 character password ব্যবহার করুন।

Biometric / Passkey

Device biometric বা passkey login-এর প্রস্তুতি।

Checking device support...

আপনার device/browser WebAuthn support করে কিনা পরীক্ষা করা হচ্ছে।

Checking
Enable Biometric / Passkey এই device-এ passkey preference চালু রাখুন।
Secure biometric authentication-এর জন্য server-side WebAuthn challenge এবং verification প্রয়োজন। এই Settings page preference সংরক্ষণ করবে; এটি একা fingerprint/face authentication server verification-এর বিকল্প নয়।

Teacher Permissions

প্রত্যেক Teacher-এর জন্য আলাদা page access নির্ধারণ করুন।

Access Rule: এখানে যে page-এর permission দেওয়া হবে, Teacher Dashboard-এ শুধুমাত্র সেই page-এর menu/card দেখতে পাবে। Permission না থাকলে page direct URL দিয়েও open করা যাবে না— সংশ্লিষ্ট page-এ permission guard থাকতে হবে।
